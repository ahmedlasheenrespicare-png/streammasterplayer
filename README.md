# مشغّل ستريم ماستر — واجهة بنمط نوفا

نسخة مستقلة من **تجربة واجهة نوفا للويب** بهوية ستريم ماستر: شعار تشغيل أسود/ليموني، أيقونات أقسام جديدة، صور رياضة وسينما من الموقع الذي قدّمته، مع الحفاظ على أقسام القنوات والأفلام والمسلسلات والمفضلة والسجل والبحث.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادمًا ثابتًا من داخل هذا المجلد:

```bash
python3 -m http.server 4175 --bind 0.0.0.0
```

ثم افتح `http://localhost:4175/`. لا تحتاج إلى `npm install` أو خادم خلفي. لإنتاج ملف HTML واحد مستقل شغّل `python3 build_standalone.py`؛ سينشئ `Stream-Master-Player.html` في المجلد الأعلى.

## الوظائف

- واجهتا عرض للهاتف والتلفاز؛ التنقل بين القنوات والأفلام والمسلسلات والمفضلة والسجل.
- البحث والتصنيف والترتيب والحفظ المحلي في المتصفح.
- استيراد ملف أو رابط M3U إذا سمحت سياسة CORS بذلك، وإضافة رابط مباشر وتشغيل MP4/WebM/HLS.
- عناصر تجريبية معلّمة بوضوح ويمكن تعطيلها من الإعدادات.
- صفحة اشتراك معلوماتية تربط إلى [موقع ستريم ماستر الأصلي](https://ahmedlasheenrespicare-png.github.io/serverproject/)؛ لا تُدخل فيها رموزًا حقيقية.

## مهم

هذه **واجهة ويب مستقلة**: لا تتصل بقنوات الموقع الأصلي، ولا تصدر اشتراكًا أو تتحقق من الرموز. المقاطع التجريبية خارجية وتتطلب الإنترنت. استخدم فقط القوائم والروابط التي تملك حق مشاهدتها. قفل العرض الأبوي محلي بسيط وليس وسيلة أمان قوية.

لا يغيّر هذا المشروع مستودعَي `novaserver` أو `streammasterserver2`. يمكنك رفع الملفات إلى مستودع **جديد**؛ ارفع محتويات المجلد بحيث يكون `index.html` في جذر المستودع مع `assets/`، ثم فعّل GitHub Pages من الفرع `main` والمجلد `/ (root)`.

الأيقونات والهوية المتجهية الجديدة في `assets/*.svg` مصممة لهذه النسخة استنادًا إلى أسلوب الموقع. الصور من موقعك المرجعي. خط Tajawal تحت SIL OFL (رخصته في `assets/fonts/`) و`hls.js` تحت Apache-2.0 (رخصته في `assets/hls-LICENSE.txt`).
